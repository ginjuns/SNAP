==============================================================
 Smart Face Kiosk 사용 방법
==============================================================

얼굴인식으로 로그인하고 결제하는 무인 키오스크 프로그램입니다.
키오스크 프로그램(KioskClient) 하나만 실행하면 서버(9000번 포트)도
함께 켜지고, 안드로이드 앱도 이 서버에 접속합니다.

  [안드로이드 앱] --회원가입(얼굴 사진)--> [키오스크 안의 서버] <--> [MySQL]
  [키오스크 화면] --얼굴인식 로그인/결제--> [키오스크 안의 서버]

폴더 구성
  qt/        키오스크 프로그램 (Qt Creator 로 qt/KioskSystem.pro 열기)
    client/    화면 (회원/관리자/얼굴인식/장바구니/키보드)
    server/    서버(앱 9000번, ESP32 8000번), DB 처리, server.ini, 통신 규격(packet.h)
  db/        kiosk.sql  (테이블 + 서버 접속 계정 만들기, 샘플 데이터 없음)
  esp32/     ESP32 코드


--------------------------------------------------------------
 1. 처음 설치 (Ubuntu, 한 번만)
--------------------------------------------------------------

1) 필요한 프로그램 설치
   sudo apt install mysql-server libqt5sql5-mysql
   sudo apt install libopencv-dev libopencv-contrib-dev opencv-data

2) 저장소 받기
   git clone https://github.com/ginjuns/Smart_Face_Kiosk.git
   cd Smart_Face_Kiosk

3) DB 만들기
   sudo mysql < db/kiosk.sql
   (root 비밀번호가 아니라 우분투 로그인 비밀번호를 묻습니다)

4) 설정 파일 만들기
   cp qt/server/server.ini.example qt/server/server.ini
   server.ini 에서 채울 값
     [mysql] user / password   kiosk.sql 의 서버 접속 계정과 같게
     [ai]    groq_key           AI 리포트/상담/예측용 Groq API 키
     [toss]  secret_key         앱 충전 승인용 토스페이먼츠 시크릿 키 (비우면 충전 불가)
     [admin] signup_code        관리자 가입 코드 (비우면 관리자 가입 불가)

5) Qt Creator 로 빌드
   - qt/KioskSystem.pro 를 열고 빌드합니다. (Qt 5 이상, 얼굴인식 OpenCV 포함)

6) 관리자 계정 만들기
   샘플 계정이 없으므로 안드로이드 앱에서 회원가입할 때 관리자 코드(signup_code)를
   입력해 첫 관리자를 만듭니다.


--------------------------------------------------------------
 2. 실행
--------------------------------------------------------------

Qt Creator 에서 실행(Ctrl+R) 하거나 터미널에서 실행합니다.

   ./KioskClient                       키오스크 + 서버 함께 실행 (항상 전체 화면)
   ./KioskClient --host 192.168.0.10   다른 PC 의 서버에 접속 (서버는 안 켬)
   ./KioskClient --scale 1.2           화면 배율 직접 지정

종료: Alt+F4

서버를 켜지 못하면(DB 연결 실패, 9000번 포트 사용 중 등) 경고창에
이유가 나옵니다.

화면 크기
   화면은 가로 1280x720 기준으로 만들어져 있고,
   실행할 때 모니터 크기를 보고 자동으로 꽉 차게 확대/축소합니다.
   - 가로 1920x1080 모니터: 1.5배
   - 화면 비율이 16:9 가 아니면 짧은 쪽에 맞춰지고 남는 쪽이 늘어납니다.
   - 글자가 너무 크거나 작으면 --scale 로 직접 지정합니다.

화면 배치 (가로)
   첫 화면      왼쪽 SNAP 로고 / 오른쪽 안내와 [얼굴인식으로 시작하기]
   얼굴인식     왼쪽 카메라 / 오른쪽 인식 상태(진행 막대), 비밀번호 로그인, 취소
   회원 화면    왼쪽 상품(4열) / 오른쪽 장바구니 (항상 보임, 결제 버튼 포함)
   관리자 화면  왼쪽 메뉴(상품 관리, 매출 확인, AI 리포트, AI 상담, 판매 예측, 로그아웃)
                / 오른쪽 내용

터치 위치가 어긋날 때 (Ubuntu)
   xinput                            <- 터치 장치 이름 확인
   xinput map-to-output "터치장치이름" HDMI-1
   (모니터 이름은 xrandr 만 입력하면 나옵니다)


--------------------------------------------------------------
 3. 회원가입 (얼굴 등록)
--------------------------------------------------------------

원래는 안드로이드 앱에서 이름/아이디/비밀번호/전화번호를 입력하고 얼굴 사진
5장을 찍어 가입합니다. 사진은 DB 의 face_images 테이블에 저장됩니다.
아이디와 전화번호는 다른 회원과 겹칠 수 없습니다.

가입하면 키오스크를 다시 켜지 않아도 다음 얼굴인식부터 바로 인식됩니다.

관리자로 가입하기
   server.ini 의 [admin] signup_code 에 관리자 코드를 적어 둡니다. (비워 두면 관리자 가입 불가)
   앱에서 가입할 때 이 코드를 입력하면 관리자로, 입력하지 않으면 일반 회원으로 가입됩니다.
   코드가 틀리면 가입되지 않습니다. (횟수 제한 없이 다시 시도 가능)

사진 잘 찍는 법
   - 밝은 곳에서, 실제 키오스크 카메라로 찍는 것이 가장 정확합니다.
   - 정면 위주로 고개 각도와 표정을 조금씩 바꿔 찍습니다.

앱 통신 규격 (9000번 포트, JSON 한 줄 + 줄바꿈, 응답 {"ok":true,"data":...} 또는 {"ok":false,"error":"..."})
   회원가입     {"cmd":"REGISTER","name","loginId","password","phone","faces":[사진Base64 x5],"adminCode"(선택)}
                -> {"userId","role"}
                adminCode 외에는 모두 필수 (빈 칸/공백만 있으면 어느 칸인지 알려 주고 거절)
                사진은 5장 이상, 장당 5MB 이하 JPEG/PNG. 비었거나 사진이 아니면 몇 번째인지 알려 줌
                아이디/전화번호가 이미 있으면 거절 (중복 확인을 했어도 가입할 때 서버가 다시 확인)
   아이디 중복 확인
                {"cmd":"CHECK_ID","loginId"}
                -> {"loginId","available":true/false,"message"}
   로그인       {"cmd":"PASSWORD_LOGIN","loginId","password"}
                -> {"id","name","role","balance","loginId","phone","token"}
                role 이 admin 이면 관리자 화면. token 은 관리자 기능에 필요하니 저장해 둠
   로그아웃     {"cmd":"LOGOUT","token"}
   아이디/비밀번호 변경
                {"cmd":"CHANGE_ACCOUNT","loginId","password","newLoginId"(선택),"newPassword"(선택)}
                -> 바뀐 회원 정보   (지금 아이디/비밀번호가 맞아야 함)
   잔액 충전    {"cmd":"CHARGE","loginId","password","amount","paymentKey","orderId"}
                -> 충전 후 회원 정보 (balance)   1회 최대 1,000,000원
                앱이 토스 결제창에서 받은 paymentKey, orderId 로 서버가 토스에 최종 승인 후 충전
                승인 뒤 충전에 실패하면 결제를 자동 취소. 같은 결제로 두 번 충전 불가
   이용 내역    {"cmd":"HISTORY","userId","from":"yyyy-MM-dd","to":"yyyy-MM-dd"(미포함)}
                -> [{"time":"yyyy-MM-dd HH:mm:ss","type":"use"/"charge","amount"}, ...] 시간순
   관리자 전용  ADD_PRODUCT / UPDATE_PRODUCT / DELETE_PRODUCT / SALES / MEMBERS / AI_REPORT / AI_ASK / AI_FORECAST
                요청에 관리자 로그인 때 받은 "token" 을 꼭 넣어야 함
                토큰이 없으면 "관리자 로그인이 필요합니다", 회원 토큰이면 "관리자만 사용할 수 있는 기능입니다"
                토큰은 로그아웃하거나 키오스크 프로그램을 다시 켜면 사라지므로 다시 로그인
                (숫자는 3000 또는 "3000" 둘 다 가능, UPDATE_PRODUCT 에서 image 를 비우면 사진은 그대로)
   상품 목록    PRODUCTS 는 누구나 (토큰 필요 없음)


--------------------------------------------------------------
 4. 로그인
--------------------------------------------------------------

1) 첫 화면에서 [얼굴인식으로 시작하기]
2) 카메라를 바라봅니다.
   - 초록 사각형: 등록된 얼굴, 5번 연속 인식되면 로그인
   - 빨간 사각형: 등록되지 않은 얼굴
   - 화면 가운데 흰색 사각형(인식 구역) 안의, 카메라 가까이 있는 얼굴만 인식합니다.
     구역 밖이나 멀리 있는(뒤에 서 있는) 사람은 회색 사각형으로 표시되고 무시됩니다.
   - 뒤 사람이 계속 인식되거나 앞 사람이 "가까이 와 주세요" 가 자주 뜨면
     qt/client/face.cpp 의 ZONE_W / ZONE_H / MIN_FACE_W 값을 조정합니다.
3) 얼굴인식이 안 될 때는 [비밀번호로 로그인]
   - 화면 키보드로 아이디 -> 비밀번호 입력 -> [로그인]
4) 관리자 계정이면 관리자 화면, 회원이면 상품 화면으로 이동합니다.


--------------------------------------------------------------
 5. 회원 화면 (상품 구매)
--------------------------------------------------------------

- 상품을 터치하면 장바구니에 1개씩 담깁니다. 품절 상품은 담을 수 없습니다.
  (재고가 0이거나, 진열대를 지정한 상품의 진열대가 비어 있으면 품절)
- 담은 뒤에 진열대가 비면 장바구니에 "(품절)" 로 표시되고 [+] 가 막힙니다.
  품절 상품이 장바구니에 남아 있으면 결제할 수 없으니 [−] 로 빼야 합니다.
- 오른쪽 장바구니에 담은 상품과 총 금액이 바로 보이고,
  [−] [+] 로 수량 변경, [비우기] 로 모두 뺄 수 있습니다.
- 결제
   [카드 결제]       카드를 리더기에 태그하면 카드 잔액에서 차감 (잔액 부족이면 다른 카드 태그)
   [얼굴인식 결제]   얼굴을 한 번 더 확인하고 충전 잔액에서 차감
- 결제하면 재고가 줄고, 처음 화면으로 돌아갑니다.
- [처음으로] 를 누르면 로그아웃됩니다.


--------------------------------------------------------------
 6. 관리자 화면
--------------------------------------------------------------

[상품 관리] 메뉴  (왼쪽 입력칸 / 오른쪽 상품 목록)
- 사진 영역을 터치해 상품 사진을 고릅니다.
- 상품명, 가격, 재고를 입력합니다. (입력칸을 터치하면 화면 키보드)
- 진열대(1번~4번)는 선택 사항입니다. 고르면 ESP32 가 그 진열대를 비었다고
  알릴 때 손님 화면에 품절로 표시됩니다. [선택 안 함] 이면 재고로만 판단합니다.
  목록의 진열대 칸에 "(비어 있음)" 이 붙으면 지금 그 진열대가 빈 상태입니다.
- 아이콘 버튼
   +        상품 추가
   연필     목록에서 고른 상품 수정
   되돌리기 입력칸 비우기 (새로 입력)
   휴지통   목록에서 고른 상품 삭제 (매출 기록은 남음)
- 같은 이름의 상품은 등록할 수 없습니다.

[매출 확인] 메뉴  (위: 날짜와 요약 카드 / 왼쪽: 그래프 / 오른쪽: 상품별 판매 표)
- 날짜를 고르면 시간대별, 월을 고르면 일자별 매출 그래프
- [◀ 이전] [다음 ▶] 로 기간 이동, [오늘] 로 오늘 매출
- 아래 표에 상품별 판매: 일별은 시간대(12시)마다, 월별은 날짜(10월 5일)마다
  상품별로 카드 / 얼굴인식 / 합계 판매 수량과 금액 (많이 팔린 상품부터)
- 다른 관리자가 로그인하면 모든 화면이 처음 상태(상품 관리, 오늘 매출)로 돌아갑니다.

[AI 리포트] [AI 상담] [판매 예측] 메뉴  (Groq AI 사용, server.ini 의 [ai] groq_key 필요)
- AI 리포트: 일별/주별/월별과 날짜를 고르고 [AI 리포트 생성]
   핵심 지표 표 (매출, 결제 건수, 객단가, 판매 수량, 구매 회원 수, 카드/얼굴인식 매출,
                 이전 기간 대비 변화율) - 숫자는 프로그램이 직접 계산
   AI 분석     (한눈에 보기, 잘된 점, 살펴볼 점, 재고·발주, 할 일)
   상품별 판매 표, 판매 없는 상품, 가장 바쁜 시간대
   오늘/이번 주/이번 달처럼 진행 중인 기간은 이전 기간의 같은 시각까지와 비교합니다.
   왼쪽에 숫자(핵심 지표, 상품별 판매), 오른쪽에 AI 분석이 나옵니다.
   AI 연결이 안 되면 숫자 표만 보여 줍니다.
- AI 상담: 질문 버튼을 눌러 매출/상품/재고/고객에 대해 질문
- AI 판매 예측: 지난 판매량으로 앞으로 7/14일 판매량, 품절 예상일, 발주 수량 예측

[로그아웃] 으로 처음 화면으로 돌아갑니다.


--------------------------------------------------------------
 7. ESP32 통신 (8000번 포트)
--------------------------------------------------------------

ESP32 는 키오스크 PC 의 8000번 포트로 TCP 접속해서 연결을 계속 유지합니다.
메시지는 단어 명령 한 줄 + 줄바꿈('\n'). 형식: 명령:값 (대소문자 구분 없음)
연결이 끊기면 ESP32 가 다시 접속해야 합니다. (새로 접속하면 이전 연결은 끊김)

ESP32 -> 키오스크 (응답 없음)
  사람 감지 (초음파)     person:1             떠나면 person:0
  카드 접촉 (RFID)       card:A1B2C3D4        card:카드UID (16진수, 공백은 무시)
  선반 물건 유무 (ToF)   stand 1:1            stand 진열대번호(1~4):1=있음 0=없음
                         바뀐 진열대만 한 줄씩 보내면 됩니다. 소식이 없는 진열대는 있음으로 봅니다.
                         (관리자 화면에서 상품마다 진열대 번호를 지정)
                         진열대가 0 이면 재고가 남아 있어도 품절로 표시되고,
                         ESP32 가 그 진열대에 1 을 다시 보내야 품절이 풀립니다.

키오스크 -> ESP32
  결제 성공 효과음       BUZZER
  카드로 결제 선택       CARD_SELECT          카드 리더기 켜기
  카드 결제 실패         CARD_FAIL            카드 잔액 부족 등. 리더기는 켜 둔 채 다른 카드 대기
  카드 결제 취소         CARD_CANCEL          카드 리더기 끄기

카드 결제 흐름
  [카드 결제] -> CARD_SELECT -> ESP32 가 card:UID 전송 -> cards 테이블에서 잔액 차감
    성공: BUZZER
    실패: CARD_FAIL (등록 안 된 카드 / 잔액 부족) -> 다른 카드를 대면 다시 결제
    [취소] 또는 사람이 떠남: CARD_CANCEL

카드 등록 (cards 테이블, 등록 화면은 없음)
  카드를 태그하면 키오스크 로그에 [ESP32] card:UID 가 찍히니 그 값으로 등록합니다.
    sudo mysql kiosk -e "INSERT INTO cards (uid, name, balance) VALUES ('A1B2C3D4', '카드 이름', 10000);"

연결 시험 (키오스크 PC 에서, ESP32 대신)
  nc 127.0.0.1 8000
  person:1                             <- 입력 후 Enter, 키오스크 로그에 [ESP32] 로 표시
  [카드 결제] 를 누르면 CARD_SELECT 가 찍히고,
  card:등록한UID 입력 -> 결제 성공(BUZZER), 등록 안 된 UID 나 잔액 부족 -> 결제 실패(CARD_FAIL)

--------------------------------------------------------------
 9. 문제 해결
--------------------------------------------------------------

Access denied for user 'root'@'localhost'
   -> mysql -u root 대신  sudo mysql  로 실행

QMYSQL driver not loaded
   -> sudo apt install libqt5sql5-mysql

server.ini 를 찾을 수 없습니다
   -> cp qt/server/server.ini.example qt/server/server.ini

포트 9000 열기 실패
   -> 다른 키오스크 프로그램이 이미 켜져 있는지 확인

얼굴인식 화면에 "OpenCV 없이 빌드되어 얼굴인식을 사용할 수 없습니다" 가 나옴
   -> sudo apt install libopencv-dev libopencv-contrib-dev 후 qmake 실행, 다시 빌드

haarcascade_frontalface_default.xml 파일을 찾을 수 없습니다
   -> sudo apt install opencv-data

등록된 얼굴이 없습니다
   -> 3번 회원가입을 먼저 하거나, 얼굴이 잘 보이는 사진으로 다시 가입

카메라를 열 수 없습니다
   -> 카메라를 쓰는 다른 프로그램을 닫기

절전모드에서 모니터가 꺼지지 않음 (검은 화면만 나옴)
   -> echo $XDG_SESSION_TYPE 로 세션 확인
      x11     : xset dpms force off 를 터미널에서 직접 실행해 꺼지는지 확인
      wayland : 로그인 화면 오른쪽 아래 톱니바퀴에서 "Ubuntu on Xorg" 로 로그인하면 가장 확실
   -> 사람이 있는데 모니터가 저절로 꺼지면 (Wayland)
      gsettings set org.gnome.desktop.session idle-delay 0
