==============================================================
 Smart Face Kiosk 사용 방법
==============================================================

얼굴인식으로 로그인하고 결제하는 무인 키오스크 프로그램입니다.
키오스크 프로그램(KioskClient) 하나만 실행하면 서버(9000번 포트)도
함께 켜지고, 안드로이드 앱도 이 서버에 접속합니다.

  [안드로이드 앱] --회원가입(얼굴 사진)--> [키오스크 안의 서버] <--> [MySQL]
  [키오스크 화면] --얼굴인식 로그인/결제--> [키오스크 안의 서버]

폴더 구성
  qt/        키오스크 프로그램 (Qt Creator 로 qt/KioskSystem.pro 열기)
    client/    화면 (회원/관리자/얼굴인식/장바구니/키보드)
    server/    서버, DB 처리, server.ini, 회원가입 테스트 도구
    common/    앱/키오스크/서버 공통 통신 규격
  db/        kiosk.sql  (DB 만들기 + 예전 DB 업데이트를 한 파일로)
  esp32/     ESP32 코드


--------------------------------------------------------------
 1. 처음 설치 (Ubuntu, 한 번만)
--------------------------------------------------------------

1) 필요한 프로그램 설치
   sudo apt install mysql-server libqt5sql5-mysql
   sudo apt install libopencv-dev libopencv-contrib-dev opencv-data

2) 저장소 받기
   git clone https://github.com/ginjuns/Smart_Face_Kiosk.git
   cd Smart_Face_Kiosk

3) DB 만들기
   sudo mysql < db/kiosk.sql
   (root 비밀번호가 아니라 우분투 로그인 비밀번호를 묻습니다)

4) DB 접속 설정 파일 만들기
   cp qt/server/server.ini.example qt/server/server.ini
   (MySQL 계정을 바꿨다면 server.ini 의 user / password 를 고칩니다)

5) Qt Creator 로 빌드
   - qt/KioskSystem.pro 를 엽니다. (Qt 5 이상)
   - 프로젝트 -> 빌드 -> qmake 단계 -> 추가 인자에  CONFIG+=opencv  입력
   - 빌드 -> qmake 실행 -> 다시 빌드
   (CONFIG+=opencv 없이 빌드하면 카메라 없이 사용자 번호를 직접 입력하는
    시뮬레이션 모드로 동작합니다)


--------------------------------------------------------------
 2. 이미 쓰던 DB 를 최신으로 맞추기
--------------------------------------------------------------

저장소를 새로 받은 뒤(git pull)나 프로그램이 DB 관련 경고를 띄우면
아래를 한 번 실행합니다. 데이터는 지워지지 않고 빠진 테이블/칸만 추가됩니다.

   sudo mysql < db/kiosk.sql

예전 암호화 비밀번호를 쓰던 DB 라면 실행 후 샘플 계정 외 회원의 비밀번호를
다시 넣어야 합니다. (예전 암호화 값은 되돌릴 수 없음)
   sudo mysql kiosk -e "UPDATE users SET password='jun1234' WHERE login_id='jun';"


--------------------------------------------------------------
 3. 실행
--------------------------------------------------------------

Qt Creator 에서 실행(Ctrl+R) 하거나 터미널에서 실행합니다.

   ./KioskClient                       키오스크 + 서버 함께 실행 (항상 전체 화면)
   ./KioskClient --host 192.168.0.10   다른 PC 의 서버에 접속 (서버는 안 켬)
   ./KioskClient --scale 1.2           화면 배율 직접 지정

종료: Alt+F4

서버를 켜지 못하면(DB 연결 실패, 9000번 포트 사용 중 등) 경고창에
이유가 나옵니다.

화면 크기
   화면은 15.6인치 모니터를 세로로 세운 1080x1920 화면에 맞춰져 있고,
   실행할 때 모니터 크기를 보고 자동으로 꽉 차게 확대/축소합니다.
   - 세로 1080x1920 모니터: 1.5배
   - 가로 모니터(개발 PC)에서는 높이에 맞춰지고 화면이 옆으로 넓게 늘어납니다.
   - 글자가 너무 크거나 작으면 --scale 로 직접 지정합니다.

키오스크 모니터를 세로로 쓰는 설정 (Ubuntu)
   1) 설정 -> 디스플레이 -> 방향 -> 세로(왼쪽 또는 오른쪽 회전) -> 적용
      또는 터미널: xrandr --output HDMI-1 --rotate left
      (모니터 이름은 xrandr 만 입력하면 나옵니다)
   2) 터치 위치가 어긋나면 터치 입력도 같은 화면에 맞춥니다.
      xinput                            <- 터치 장치 이름 확인
      xinput map-to-output "터치장치이름" HDMI-1
   3) ./KioskClient


--------------------------------------------------------------
 4. 회원가입 (얼굴 등록)
--------------------------------------------------------------

원래는 안드로이드 앱에서 이름/아이디/비밀번호를 입력하고 얼굴 사진을
찍어 가입합니다. 사진은 DB 의 face_images 테이블에 저장됩니다.

앱 없이 테스트할 때는 웹캠 사진으로 가입할 수 있습니다.
(키오스크 프로그램이 켜져 있어야 합니다)

   1) cheese 로 정면 사진 5~10장 촬영 (사진 모드)
      -> ~/사진/Webcam/ 또는 ~/Pictures/Webcam/ 에 저장됨
   2) python3 qt/server/register_test.py 이름 아이디 비밀번호 ~/사진/Webcam/*.jpg
      예) python3 qt/server/register_test.py 엄준식 jun jun1234 ~/사진/Webcam/*.jpg
   3) {'ok': True, 'data': {'userId': 4}} 가 나오면 가입 완료

가입하면 키오스크를 다시 켜지 않아도 다음 얼굴인식부터 바로 인식됩니다.

사진 잘 찍는 법
   - 밝은 곳에서, 실제 키오스크 카메라로 찍는 것이 가장 정확합니다.
   - 정면 위주로 고개 각도와 표정을 조금씩 바꿔 찍습니다.


--------------------------------------------------------------
 5. 로그인
--------------------------------------------------------------

1) 첫 화면에서 [얼굴인식으로 시작하기]
2) 카메라를 바라봅니다.
   - 초록 사각형: 등록된 얼굴, 5번 연속 인식되면 로그인
   - 빨간 사각형: 등록되지 않은 얼굴
3) 얼굴인식이 안 될 때는 [비밀번호로 로그인]
   - 화면 키보드로 아이디 -> 비밀번호 입력 -> [로그인]
4) 관리자 계정이면 관리자 화면, 회원이면 상품 화면으로 이동합니다.

샘플 계정
   아이디   비밀번호    권한
   admin    admin1234   관리자
   hong     hong1234    회원 (잔액 50,000원)
   kim      kim1234     회원 (잔액 30,000원)


--------------------------------------------------------------
 6. 회원 화면 (상품 구매)
--------------------------------------------------------------

- 상품을 터치하면 장바구니에 1개씩 담깁니다. 품절 상품은 담을 수 없습니다.
- 아래 장바구니 바에 총 금액이 보이고, [장바구니] 를 누르면
  수량 변경 / [비우기] / [계속 쇼핑] 을 할 수 있습니다.
- 결제
   [카드 결제]       카드를 단말기에 태그한 뒤 [예]
   [얼굴인식 결제]   얼굴을 한 번 더 확인하고 충전 잔액에서 차감
- 결제하면 재고가 줄고, 처음 화면으로 돌아갑니다.
- [처음으로] 를 누르면 로그아웃됩니다.


--------------------------------------------------------------
 7. 관리자 화면
--------------------------------------------------------------

[상품 관리] 탭
- 사진 영역을 터치해 상품 사진을 고릅니다.
- 상품명, 가격, 재고를 입력합니다. (입력칸을 터치하면 화면 키보드)
- 아이콘 버튼
   +        상품 추가
   연필     목록에서 고른 상품 수정
   되돌리기 입력칸 비우기 (새로 입력)
   휴지통   목록에서 고른 상품 삭제 (매출 기록은 남음)
- 같은 이름의 상품은 등록할 수 없습니다.

[매출 확인] 탭
- 날짜를 고르면 시간대별, 월을 고르면 일자별 매출 그래프
- [◀ 이전] [다음 ▶] 로 기간 이동, [오늘] 로 오늘 매출
- 아래에 구매 상세 내역(일시/구매자/상품/수량/금액/결제수단)과
  구매자·상품별 합계

[로그아웃] 으로 처음 화면으로 돌아갑니다.


--------------------------------------------------------------
 8. DB 직접 보기 (MySQL Workbench)
--------------------------------------------------------------

접속: Hostname 127.0.0.1 / Port 3306 / Username kiosk / Password kiosk1234
(root 로는 접속되지 않습니다)

   USE kiosk;
   SELECT id, name, login_id, password, balance FROM users;   -- 회원
   SELECT id, name, price, stock FROM products;              -- 상품
   SELECT * FROM sales ORDER BY sold_at DESC;                -- 매출
   SELECT id, user_id, image FROM face_images;               -- 얼굴 사진

얼굴 사진 보기: image 칸 오른쪽 클릭 -> Open Value in Editor -> Image 탭

회원 잔액 충전 예:
   sudo mysql kiosk -e "UPDATE users SET balance = balance + 10000 WHERE login_id='jun';"


--------------------------------------------------------------
 9. 문제 해결
--------------------------------------------------------------

Access denied for user 'root'@'localhost'
   -> mysql -u root 대신  sudo mysql  로 실행

QMYSQL driver not loaded
   -> sudo apt install libqt5sql5-mysql

server.ini 를 찾을 수 없습니다
   -> cp qt/server/server.ini.example qt/server/server.ini

포트 9000 열기 실패
   -> 다른 키오스크 프로그램이 이미 켜져 있는지 확인

얼굴인식 화면에 "시뮬레이션 모드" 가 나옴
   -> qmake 추가 인자 CONFIG+=opencv 확인 후 qmake 실행, 다시 빌드

haarcascade_frontalface_default.xml 파일을 찾을 수 없습니다
   -> sudo apt install opencv-data

등록된 얼굴이 없습니다
   -> 4번 회원가입을 먼저 하거나, 얼굴이 잘 보이는 사진으로 다시 가입

카메라를 열 수 없습니다
   -> cheese 등 카메라를 쓰는 다른 프로그램을 닫기

register_test.py 에서 FileNotFoundError ... *.jpg
   -> 그 폴더에 사진이 없음. 사진 폴더 경로 확인 (~/사진 또는 ~/Pictures)
